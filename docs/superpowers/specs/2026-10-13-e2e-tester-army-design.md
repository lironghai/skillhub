# E2E Tester Army 接入设计

## 合同

在 `skillhub/web` 中增加 E2E Tester Army 的配置、生成示例和一个覆盖核心用户流程的测试，并保留现有 Playwright 测试体系。目标地址为 `http://127.0.0.1:3000`，开发服务使用现有 Vite 命令。

## 行为规则

- 使用仓库现有的 `pnpm` 包管理器和前端工作目录，不在父目录创建第二套前端配置。
- 按 E2E Tester Army 官方初始化结果配置 Web 测试、技能文件和 MCP 配置；模型提供方由用户选择后再完成登录或密钥配置。
- 先运行官方生成的示例测试，修复初始化、依赖、服务启动和浏览器执行问题，再添加核心流程测试。
- 核心流程测试优先覆盖匿名用户进入首页并导航到公开技能浏览/详情路径，因为该路径不依赖外部账号登录。

## 范围边界

- 不替换或重写现有 `web/e2e` Playwright 测试。
- 不修改业务代码，除非测试暴露出阻塞测试运行的明确配置错误。
- 不提交 API 密钥、登录令牌或本地生成的敏感凭据。

## 验收标准

1. E2E Tester Army 配置指向 `http://127.0.0.1:3000`，并包含可执行的前端启动命令。
2. 依赖安装成功，官方示例测试实际运行通过。
3. 新增的核心用户流程测试实际运行通过。
4. 失败若来自外部服务、模型登录或本地运行环境，必须明确标记为环境阻塞，并保留可复现命令。
